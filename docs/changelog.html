2026-08-05 · 0.2.1 发布 + 报表查询打通
财务报表查询经实测打通：科目余额表、试算平衡表、账龄分析表等通过金蝶专用报表接口 GetSysReportData 正常出数；改用账号密码(ValidateUser)登录的原因说明已订正（以真实用户身份执行、携带自身业务权限）；并通过 PyPI 可信发布(OIDC)免 token 发布 0.2.1。

新增财务报表查询与通用导出能力，覆盖科目余额表、试算平衡表、账龄分析表、总账等总账报表，统一走金蝶 WebAPI 专用报表查询服务 GetSysReportData（非普通单据 formid）。
